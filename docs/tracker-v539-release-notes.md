# Tracker v539 Alpha: EFB-Audio und Mediensteuerung

EFB und Toolbar erhalten sichtbare SVG-Häkchen sowie direkte Skin-/Auswahltasten
anstelle nativer Select-Popups. Eine explizit dimensionierte Medienebene unter
der Menüleiste verhindert die winzige Darstellung und verdeckte Startknöpfe.
Legacy-Maus und Touch bedienen dieselben Gerätegesten auch ohne Pointer Events
oder Pointer-Capture. Winamp nutzt einen Flex-Fallback für Coherent ohne CSS Grid
und flex-gap. Die redundante Anzeige „Tracker verbunden“ entfällt.

Vier Browserfälle mit bewusst deaktiviertem inset/Grid/gap/Pointer-Support,
Audio-Synchronisierung mit 18 Sliderfällen, 32 Asset-/Parser-/Transportprüfungen
und vollständige EFB-/Toolbar-Medienintegration bis zur privaten Desktop-Bridge
bestanden. Echte MSFS-/Coherent-/VR-Abnahme bleibt dem Alpha-Feldtest vorbehalten.

Webapp-Skins, Desktop 1.6.16, MSFS-Community-Paket und Stable bleiben unverändert.
