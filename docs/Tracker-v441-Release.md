# Tracker v441 / Charter-Fortsetzungen – Alpha

Charter-Folgemissionen erhalten einen gespeicherten Aufenthalt, denselben Kunden samt Gruppe und Gepäck sowie einen nachvollziehbaren Rückreiseauftrag. Neue Charterideen entscheiden ausdrücklich, ob eine Rückreise dazugehört. Der Tracker erzeugt nach bestätigtem Hinflug denselben dauerhaften Follow-up-Vertrag wie die App.

Direkte Rückflüge verwenden die bestehende APT-Tracker-Ausführung. Abholungen mit Zwischenlandung bleiben App-authoritativ. Die neuen Gespräche sind optional und auf den besetzten Rückflug beschränkt. Der Erzählstil beschreibt Rückblick, aktuellen Stand und nächsten Schritt ohne konkrete Beispielgeschichte im Prompt.
