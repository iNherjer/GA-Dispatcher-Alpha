GAFOR Sektor Topologie Editor (Extern)
Gemeinsame Grenzen bleiben verbunden: Wenn du einen Knoten ziehst, wandern benachbarte Sektoren mit. Rechtsklick auf Knoten entfernt ihn (wenn moeglich). Insert-Modus: Klick auf Segment fuegt Knoten ein. Loesen-Modus: Klick auf Knoten loest ihn im aktiven Sektor. Snap kann Knoten beim Loslassen verbinden.
