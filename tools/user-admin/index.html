    Technische Details
    –
    Verbindung / erweiterte Einstellungen

    Beim Start über die .command-Datei arbeitet das Tool über den lokalen Cloudflare-Proxy. Dafür ist kein Admin-Token im Browser nötig.

    PIN ändern

    Die bestehende PIN wird nicht angezeigt. Mit der neuen PIN muss sich der Nutzer in App und Tracker erneut anmelden.

    Vor dem Speichern wird das Konto erneut geprüft und lokal gesichert.

    Login-/Pilot-ID ändern

    3–40 Buchstaben, Zahlen, Bindestriche oder Unterstriche. Groß-/Kleinschreibung unterscheidet keine Konten.

    Die bisherige Pilot-ID wird gesperrt. Cloud-Profil, Homebase, Audio, Crew-Rollen und eigene Community-Checklisten bleiben zugeordnet. Die PIN bleibt gleich. Danach in App und Tracker mit der neuen ID anmelden.
