# Publisher v0.4.0 starten

Für v0.4.0 ist ausschließlich der CMD-/Node-Starter mit den aktuellen Quellen maßgeblich. Die vorhandene EXE ist nur ein historischer Fallback und soll nicht für diese Version verwendet werden.

Diese Ausgabe wird mit `Start Homebase Asset Publisher.cmd` gestartet. Sie verwendet Node.js und die aktuellen `.mjs`-Quellen des Publishers.

Eine ältere EXE wird bewusst nicht in das v0.2.0-ZIP übernommen, weil für sie keine reproduzierbare Packaging-Konfiguration vorliegt. So kann keine veraltete EXE versehentlich den aktuellen Publisher ersetzen.
