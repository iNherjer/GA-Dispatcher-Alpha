01 / Web app · For cloud, crew & live connection

One pilot.
On all your devices.

Your pilot ID is your shared profile for Multitool, tablet and tracker. The PIN protects access. You create both in the web app first.

Where to find itMultitool → open “Settings” at the bottom → “Pilot Identity & Sync”
  1. Choose your own pilot ID

    Enter a unique name in “Pilot ID”. Later, use exactly this ID on every device.

  2. Set a PIN with 4 to 8 digits

    Enter it in “PIN” and keep ID and PIN safe. The PIN is not your AI key.

  3. Click “Login”

    A new, still free ID is created this way. If it is already taken, you need its PIN or choose a different ID.

  4. Turn on “Auto-Sync”

    Your saved content is then matched with the cloud automatically. Sign in on your tablet with the same details.

Why do I need this?

So that your devices belong to the same pilot: saved missions, private pinboard, cloud sync and live connection can then work together. For pure map planning you can start without a profile at first.

How you know it worked

The app reports a successful sign-in. “Auto-Sync” can then be enabled.

What do “Push” and “Pull” mean?

“Push” writes your current state to the cloud. “Pull” fetches the cloud state to this device. With auto-sync you rarely need the buttons day to day. If states differ, first check which device has the data you want.

02 / Web app · Optional

More story
for your flight.

The AI adds individual briefings, passengers and backgrounds to jobs. Your personal API key connects the Multitool with Gemini or OpenAI for this. One provider is enough to start.

Where to enter the keyMultitool → “Settings” → “AI Dispatcher”
  1. Choose a provider

    Under “Provider” choose Gemini or ChatGPT (OpenAI). The key must belong to the chosen provider.

  2. Create a key with the provider

    The short guides below take you to the official page. A normal chat login alone is not an API key.

  3. Paste the key into the matching field

    Paste it into the Gemini or OpenAI API key field and check the status message. Turn on “AI on/off”; you can leave the profile on “Auto” for now.

How to get a Gemini key

  1. Open Google AI Studio and sign in

    Open the API key page with your Google account.

  2. Choose “Create API key”

    Use a project offered there or create one. Follow the steps shown and copy the created key.

  3. Paste it at Gemini in the Multitool

    Check in AI Studio which quota and billing apply to your project. Depending on model and usage, costs may arise.

Open Google AI Studio ↗

Official help: Create and manage Gemini API keys.

How to get an OpenAI key

  1. Open the OpenAI platform and sign in

    Open the API key area of your project.

  2. Create a new API key

    Choose “Create new secret key” and copy the key. Keep it for the tracker setup later.

  3. Check API billing and paste it into the Multitool

    Check credit, billing and usage on the platform. The API is billed by usage; a chat login does not replace the API setup.

Open OpenAI API keys ↗

Official help: API quickstart · Usage pricing.

Important: An API key is a personal access key. Do not share it via the crew pinboard or screenshots. For AI requests, the content needed is sent to your chosen provider.

You can also start without AI

With AI switched off, map planning and locally generated jobs remain available. You can add the key later.

Is my key transferred to other devices?

The web key belongs to the respective browser and is not synced via your pilot profile. If you want to use AI on another device, enter it there again. The start window can offer to remember it for further visits on this device; this local website storage is not encrypted.

03 / Web app · Optional

A shared place
for your flight ideas.

The private pinboard is yours. The crew board is your shared pinboard for routes, jobs and notes. Everyone flies with their own pilot ID; the crew code brings the group together.

Where to set up the crewMultitool → “Settings” → “Crew Board”
  1. Sign in with your pilot ID

    The crew feature requires your sign-in from step 1.

  2. Enter a shared crew code

    Ask your group for their code or agree on a new one. Everyone uses the same crew code; the personal pilot ID stays different for each person.

  3. Display name and “Join / Update”

    The display name is optional. Then open “Pinboard” on the main page and switch between “Private” and “Crew”.

Private: for your ideas

Keep favourite routes, notes and accepted flights for later. With auto-sync also available on other devices.

Crew: for shared plans

Share notes and accepted flights with the group. You can pin a flight to the crew straight from the briefing.

How you know it worked

Your crew is connected and the crew board opens. It shares your planning; for flying together you still use the simulator’s multiplayer features.

04 / Windows PC · For live features

Now your
simulator joins in.

The tracker runs on the Windows PC with MSFS. It delivers position and flight data to the Multitool – on your tablet too. Use the same pilot ID and PIN as in the web app.

Download & sign-inWeb app → “Settings” → “Pilot Identity & Sync” → install tracker
Then in the Windows tracker → “Konto” (account)
  1. Install the tracker on the simulator PC

    Use the download in the app and start the installed program. Let it load the required tracker version.

  2. Enter the same details in the “Konto” module

    Your existing pilot ID and its PIN. Then click “Prüfen & verbinden” (check & connect).

  3. Start tracker and simulator

    If needed, switch the tracker on with “Tracker starten” (start tracker). Load a flight in the simulator and keep the Multitool open with the same ID.

Why sign in again?

Browser and Windows tracker are two separate programs. The shared pilot ID assigns both to the same pilot. Without a matching sign-in, the Multitool does not know which sim data belongs to you.

LINK

The tracker is connected, but no fresh sim flight data is arriving yet. Load a flight in the simulator.

LIVE

Current sim data is arriving. Open the map table and check that your aircraft position appears.

“Pilot ID not found” or “wrong PIN”?

Create the profile in the web app via “Login” first. Then use the same ID and PIN in the tracker. For an existing pilot you need their original PIN.

05 / Tracker · Optional

Hear voices.
Leave room for the radio.

In the audio module you decide where you hear announcements. For the central AI speech output you store a provider and its API key here.

Where to find the settingsWindows tracker → “Audio” → “Zentrale Sprachausgabe” (central speech output)
  1. Choose output and volume

    Turn on “Audio aktiviert” (audio enabled), choose your headset or speakers as “PC-Ausgang” (PC output) and check the volume.

  2. Enter provider and key

    Choose Gemini or OpenAI, paste a valid key of this provider into “API-Key” and click “Sicher speichern” (save securely). You can use the key from step 2 here too if it allows the required speech generation.

  3. Tune voices and effects

    Under “Stimmen, Effekte und Warnungen” (voices, effects and warnings) choose the outputs you want. You also control passenger voices and warnings in the audio menu of the map table.

Saving a voice key restarts a running tracker. Do this step before your flight.

Why enter the key twice?

The web app uses its key for AI briefings. The tracker needs its own stored access for the central speech output, which EFB and toolbar also use. Your browser key is not transferred there automatically. The tracker protects the stored voice key with your Windows account.

Lower the music during announcements

Open your Windows music player. In the audio module, choose it under “Musik / Windows-Player”. “Bei Stimmen und Warnungen leiser” (quieter for voices and warnings) lowers the music temporarily; you can set the remaining volume.

Radio pause for your talk button

Enable it under “Funk-Pause (PTT)” and teach your key or joystick button via “+ Button hinzufügen” (add button). Voices and warnings pause or get quieter; the music can be lowered too. “Automatisch weiter nach” (continue automatically after) leaves time for the radio reply after releasing.

React to talking programs

Turn on “Programme automatisch erkennen” (detect programs automatically) and use “+ Programm hinzufügen” (add program) to select, for example, your radio program while it is playing sound. The output can then pause or get quieter as well. This evaluates the audio level; nothing is recorded. The radio pause applies to the PC output.

Where do I see the radio pause?
For a calm first test

Choose the PC output you want, start with a moderate volume and try the radio pause as soon as voices or music are playing. A stored key alone does not trigger an announcement yet.

06 / Tracker · Optional

One start button
for your flying evening.

With autostart, the tracker opens your flight programs in the order you want. You can add pauses and have individual helpers start only once the simulator is ready.

Where to set up the start listWindows tracker → “Autostart”
  1. Turn on “Autostart aktivieren”

    At the top, “Tracker & Sim starten” (start tracker & sim) appears. That will be your shared start button.

  2. Use “Sim erkennen” (detect sim)

    Let it find your installed MSFS version and pick the one you want if there are several.

  3. Add your programs

    Drag programs or shortcuts into the start list or choose them via “Importieren” (import). Adjust the order by dragging or with the arrows; “Danach warten” (wait afterwards) sets the pause until the next entry.

  4. Drag helpers needed later below the divider

    Below “Auf SimConnect warten” (wait for SimConnect) they only start once the running tracker gets stable data from the simulator.

Autostart here means: start together.

The list runs via “Tracker & Sim starten”. The module does not set up Windows autostart at boot. Programs that are already running are skipped.

What does “Mit dem Sim schließen” (close with the sim) do?

It lets you close the programs this autostart started itself once the sim ends. Programs that were already running are not included; the simulator itself is not closed by this.

07 / Tracker · Optional

Take the Multitool
into the cockpit.

Once the basic connection works, you can install matching add-on packages. You do not need all of them for the first test in the browser.

Where to manage add-on packagesWindows tracker → expand the module you want

VFR Multitool EFB · for MSFS 2024

Open the tracker module of the same name and follow the installation. Close MSFS for the package installation and restart it afterwards. You get access to the Multitool in the cockpit EFB and via the toolbar panel – helpful in VR too.

Homebase Asset Pack · for your own base

The object package provides the models for hangar and equipment. Install it via the Homebase module if you want to design your base in the simulator. You open the designer in the web app via the Homebase blueprint.

Updates · prepare before the flight

The tracker app manages its updates and those of the add-on modules. For a normal start, the preselected Stable channel is fine. Alpha is meant for targeted tests.

Connection first, then extras.

To begin with it is enough to connect web app and tracker with the same pilot ID and check the live position. After that, add only the cockpit and Homebase features you want to use.

The tracker views shown come from the interface without a Windows or simulator connection. Your installed tracker also shows the actual state of your packages and devices.

08 / Try it together

And now:
your first flight.

You don’t need to have set up everything. Start with a short route and the features you have chosen.

  1. Choose departure airfield and aircraft in the Multitool

    For example your familiar home airfield and a matching aircraft preset.

  2. Try free flight or a job

    For a quick map test, open the map table and use “Direct To”. For a job: generate a mission, read the briefing and choose “Accept mission”.

  3. Load the flight already on the world map

    With the tracker running and the EFB package installed, open the VFR Multitool in the EFB on the MSFS 2024 world map. In the planning note choose to send the flight plan to ATC, check that it was taken over, check your aircraft and load the flight in the simulator.

  4. When flying live, check the position

    In the loaded cockpit, check the live position on the map table. It should match your aircraft in the simulator.

  5. Start a mission deliberately

    With an accepted job and a connected tracker, stand still on the ground. Then choose “Start mission” on the map table. A Direct To free flight does not need this step.

Continue an interrupted flight

This also works on the world map: with the tracker running, open the VFR Multitool in the EFB and choose to load the save point on the stored job as soon as the action is offered. Note the confirmation and hints, choose the matching aircraft and load the flight in the simulator. In the cockpit, the resume hints take you back into your previous job. You need neither a new job nor a mission reset for this.

If the interruption happened in the air, the re-entry can be prepared as an air start at the save point. You can then load the flight plan into the avionics if needed.

Your personal checklist

    The entries are based on your ticks. The guide does not check actual accounts or connections. You can catch up on open extras later via the step selection.

    Open Multitool ↗

    The guide stays open for reference.

    No live position?

    First check that pilot ID and PIN match in web app and tracker. Is the tracker running and a flight loaded in the simulator? “LINK” does not confirm fresh flight data yet; “LIVE” shows the active transfer.

    The briefing works, but I hear nothing?

    In the tracker, check the voice key and its provider, “Audio aktiviert”, the PC output and the volume. Also check the voices you want in the map table audio menu and whether a radio pause is active. An AI briefing alone does not create a spoken mission moment.

    Crew board stays empty or is locked?

    First sign in with your own pilot ID, check the shared crew code and click “Join / Update”. Then open “Pinboard” → “Crew”. A new board may not contain any shared notes at first.
