Neu gesetzte oder bewusst bewegte Objekte erscheinen weiterhin sofort. „Vorschau neu laden“ baut Hangar und Ausstattung vollständig neu auf. „Vorschau entfernen“ entfernt nur die vorübergehend von der Workbench erzeugten Objekte.

05

Flugplatz bauen

Homebase-Assetpaket wird geprüft …

Der PC-Tracker ab v288 prüft den veröffentlichten Assetkanal und verwendet sein eingebettetes Paket als Offline-Fallback. Ein Download oder Austausch erfolgt ausschließlich nach deiner Bestätigung und wird per SHA-256, Dateiindex, Manifest und Layout kontrolliert.

Ein Assistent erstellt das Projekt, bittet vor dem Beenden von MSFS um Erlaubnis, baut das Paket mit dem offiziellen SDK und fragt anschließend vor der Installation in Community2024 noch einmal nach.

Entfernt nach einer Sicherheitsabfrage nur den installierten Homebase-Flugplatz aus dem Community-Ordner. Assetpaket, Workbench und gespeicherter Entwurf bleiben erhalten.

  2. Simulator schließen
  3. Paket mit SDK bauen
  4. In Community2024 installieren
  5. Fertig

Hilfe: MSFS 2024 SDK fehlt

Das SDK enthält das offizielle Package Tool. Es übersetzt die Homebase-Beschreibung in eine BGL-Datei, die MSFS als Flugplatz laden kann.

  1. In MSFS 2024 den Entwicklermodus aktivieren.
  2. Oben in der DevMode-Menüleiste Help/Hilfe → SDK Installer wählen und die heruntergeladene MSI-Datei ausführen.
  3. Den vorgeschlagenen Standardordner C:\MSFS 2024 SDK verwenden.
  4. Workbench danach erneut starten und „Flugplatz bauen“ wiederholen.
